# Layout: intro-visual

A text column on the left and one square visual on the right (347×347 at x 860, y 150), in the same place on every
slide that uses it.

- Use: the introduction slides (speaker, studio, agenda) where a face, a photo or the brand block helps.
- Lead: `.sa-lead.sa-intro-lead` (720px wide, so it stops before the visual).
- Label: `.sa-intro-label`, mono caps with a red square, above the list (top 262).
- List: `.sa-list.sa-intro-list` (top 296).
- Visual: `img.sa-intro-visual` (photo, cover-cropped) or `div.sa-intro-visual.is-brand` with the white wordmark on red.
- Don't: use it for technical content; the visual is decoration, not a figure.
