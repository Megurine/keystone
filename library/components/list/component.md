# Component: list

`ul.sa-list`, 24px, 18px between items. The marker carries meaning:

- plain `li` — red 12px square: a neutral point.
- `li.pro` — white square with **+**: an advantage.
- `li.con` — red square with **−**: a drawback.
- `<em>` inside an item — grey aside (a number or a precision, often in parentheses).

Placement: `.is-placed` puts the list in the content area (left 73, top 170, or 262 after a lead). Inside a card the
theme sets 20px.

Rules: one line per item when possible, two at most; 2–6 items; do not mix pro/con with plain items in one list; no
other font size.
