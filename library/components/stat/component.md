# Component: stat

`p.sa-stat`: a big value in Poppins 34 (`.is-large` 40), tabular numbers, on one line. `<small>` holds the unit (mono
15, grey); `.is-key` or a `<span>` makes the value red.

- Use: measured values and counts (13.7&nbsp;px/cm, 2,073,600 pixels), inside a card or under a figure.
- Numbers in the format of the deck's language (French: 13,7&nbsp;px/cm, 2&nbsp;073&nbsp;600), with a non-breaking space
  before the unit.
