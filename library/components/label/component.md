# Component: label and heading

- `.sa-label` — mono 12, caps, letter-spacing .12em, grey: card eyebrows, axis names, the name of a view in its corner,
  small context lines. `.is-marked` adds the red 12px square before it; `<b>` shows a value in white.
- `.sa-heading` — Poppins 26 bold: a heading inside the content (a column, a row of figures, a block). `.is-small`
  (22) inside cards. `<em>` for a grey precision. Use `h3` (the slide title is the `h2`).

Rules: no other heading size in the content area; the slide title stays the biggest text.
