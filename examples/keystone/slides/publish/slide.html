PUBLISH

Publish a talk anywhere

$ node tools/deploy.mjs decks/my-talk --out site/public

talks/my-talk/      the reader, the slides in each language, thumbnails
talks/_shared/      theme, components, three.js
talks/index.json    every talk published there
  • Read-only: arrows, overview, full screen, languages
  • Only the slides leave: no briefs, notes or feedback
  • Any static host: your website, GitHub Pages…

Its settings: the publish block of deck.json.
